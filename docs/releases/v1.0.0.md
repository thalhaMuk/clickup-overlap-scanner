# ClickUp Overlap Scanner v1.0.0

Initial public release.

## Download

Download `clickup-overlap-scanner-v1.0.0.zip` from the release assets.

## Install

1. Extract `clickup-overlap-scanner-v1.0.0.zip`.
2. Open Brave or Chrome.
3. Go to `brave://extensions` or `chrome://extensions`.
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted `clickup-overlap-scanner-v1.0.0` folder.

The selected folder must directly contain `manifest.json`.

## What's Included

- Scans visible ClickUp Timesheet rows for overlapping time ranges.
- Highlights conflicting rows in ClickUp.
- Provides a popup button to clear highlights.
- Uses Manifest V3 for Chromium-based browsers.
